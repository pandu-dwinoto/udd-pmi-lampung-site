Buat akun editor

Buat akun pertama untuk melindungi CMS. Setup hanya tersedia di server lokal ini dan akan ditutup sesudah akun tersimpan.

Gunakan kata sandi baru yang tidak pernah dikirim lewat chat. Minimum 14 karakter. Kata sandi disimpan sebagai hash; server hanya dapat diakses dari komputer ini.
